# yakiedits.com

Personal landing page for **YAKI** — video editing for gaming YouTubers.

- `index.html` — the entire site (self-contained HTML/CSS/JS)
- `assets/` — logo, client PFPs and video thumbnails

## Run locally
Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy
The site is static, so any static host works (GitHub Pages, Vercel, Netlify).
